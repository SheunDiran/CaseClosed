A fictional gallery-theft mystery. Inspect original records, test what a camera could see, and support a verdict. This is an offline-readable reference route, not a claim that a learner completed a hands-on code tour.

One real action through the code

1. Test both displays
public/game/app.js — search camera-helix, camera-spare, then verify-camera. The UI records both attempted camera sightlines.
2. Verify the source
public/game/engine.js — cameraSightline and verifyCamera. The partition blocks the spare; verification also requires the archive source and both hypotheses tested.
3. Use the derived evidence
public/game/engine.js — evaluateTheory. The verdict requires the reconstruction, original frame and ledger, so selecting the right suspect alone is insufficient.

The opening, sound and skip behavior

public/game/app.js: boot, startOpening, playScore, pauseScore, fadeSceneVolume. Persistent audio elements are in public/game/index.html. Original music synthesis is in scripts/audio/create-score.py.

The case story or witness lines

public/game/engine.js contains records and characters. lib/witness-lines.mjs supplies permitted server dialogue. app/api/witness/route.ts returns authored replies without configured model credentials.

The look and mobile layout

public/game/style.css owns palette, typography, animation and responsive rules. Keep evidence legible and respect reduced motion.

A practice to reuse

Translate a wish into observable evidence. “Music should work” became “check the playback promise, show Enable sound if blocked, then confirm time advances after a tap.” The fresh browser rejected autoplay; the fallback and tap succeeded. See prd.md > Automatic Opening and Sound and app.js > playScore. A rejected browser promise is useful evidence, not something to hide behind a playing label.

Run it again

Full application: install the pinned dependencies and run pnpm dev; open the printed address. Checks: pnpm test. Static-only gameplay: python3 -m http.server 8000 --directory public, then open http://localhost:8000/game/; typed API questions require the full server.
